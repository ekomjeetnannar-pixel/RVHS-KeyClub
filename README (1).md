# RVHS Key Club — Division 14

A multi-page GitHub-ready version of the RVHS Key Club website.

## Files

- `index.html` — Home
- `about.html` — About Us
- `impact.html` — Impact / Role at RVHS
- `contribute.html` — Member Contributions & Opportunities
- `events.html` — Upcoming Events
- `contact.html` — Contact
- `style.css` — Shared styling
- `script.js` — Shared JavaScript interactions
- `assets/` — Logo and website photos

## GitHub Pages

1. Upload all files and the `assets` folder to the repository root.
2. Make sure `index.html` is in the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select the branch containing these files and the `/ (root)` folder.
5. Save. GitHub Pages will use `index.html` as the homepage.

All page navigation uses relative links, so it works directly from GitHub Pages without a framework or build step.
