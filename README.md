# River Valley Key Club Website

A static site for the River Valley High School Key Club. No build step, no
dependencies — just HTML, CSS, and a little vanilla JS.

## Files

```
index.html        the whole page
css/styles.css     all styling
js/script.js       mobile nav toggle
assets/rv-falcon-logo.png   the Falcons crest, used in the header, hero, and footer
```

## Adding this to GitHub

1. Create a new repository (or use an existing one) on GitHub.
2. Copy everything in this folder into the repo, keeping the folder structure
   above intact.
3. Commit and push.
4. To host it for free with GitHub Pages: repo **Settings → Pages → Deploy
   from a branch**, pick `main` and the `/ (root)` folder, save. Your site
   will be live at `https://<username>.github.io/<repo-name>/`.

## What to edit before you publish

A few spots in `index.html` are placeholders — search for `EDIT ME`:

- **Meeting info** — day, time, and room in the "Meetings" section
- **Upcoming projects** — swap in your club's real events and dates
- **Officers** — names for each role
- **Contact info** — the club email address and social handle

Everything else (copy, colors, layout) is safe to tweak directly in
`index.html` and `css/styles.css`.
